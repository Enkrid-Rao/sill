# Sill 0.6.1

更新提醒。0.6.0 已经把组件平台做成稳定版，这一版解决「有更新但用户不知道」的问题。

## 亮点

- **托盘气泡**：发现新版本或下载完成时，Windows 托盘弹出提醒；点气泡直接打开设置；
- **面板提醒条**：面板底部常驻一条更新提示——
  - 发现新版本 → 「下载」；
  - 下载中 → 显示进度；
  - 下载完成 → 「重启更新」，也可以点「稍后」收起；
- 手动检查与自动下载两种模式都覆盖；同一版本只提醒一次。

## 下载

| 文件 | 说明 |
|---|---|
| `Sill-Setup-0.6.1.exe` | 安装版（per-user，支持自动更新） |
| `Sill-0.6.1-portable-win64.zip` | 绿色版（解压即用，数据在 `Sill-data`） |
| `latest.yml` / `.blockmap` | 自动更新元数据 |

要求 Windows 10 / 11 x64。

## 升级

安装版会通过应用内更新检查收到 0.6.1；下载完成后可立即重启安装，或退出时自动安装。
绿色版替换文件夹即可，`Sill-data` 保留。

## English

Sill 0.6.1 adds update reminders: a Windows tray balloon plus a persistent in-panel banner when an
update is available, downloading, or ready to install. The banner can start the download or restart
to install. Same version notifies once. Windows 10/11 x64.

# Sill 0.6.0

首个稳定版组件平台。侧边廊、系统 / 媒体 / 天气 / 待办这些外壳功能保持原样，这一版把「组件」从预览做成了可用产品。

## 亮点

- **模板组件**：`widget.json` + `ui/index.html` + `ui/style.css` + 可选 `ui/main.js`，在面板的 Shadow DOM 里运行，直接继承玻璃、圆角、token 与布局；
- **组件设置**：`widget.json` 里声明 `settings`，宿主渲染表单（text / number / switch / select），组件用 `sill.settings` 读写；
- **安装与信任**：`.sill` 安装 / 卸载，按包内容计算能力档位（静态 / 脚本 / 隔离 / 完整 Node）分级提示，`trust.json` 记住确认结果；
- **分发**：支持从 https 直链安装、只读组件目录、一键更新；启动后每 6 小时后台检查更新（只提示，不自动安装）；
- **官方组件仓库**：[Sill-Components](https://github.com/Enkrid-Rao/sill-Components) 现在带可安装官方组件，首个是 `sill.lyrics`（同步歌词）；
- **内置迁移**：`system` / `processes` 改为随应用发布的模板包，与第三方模板共用同一渲染路径；
- **Web 组件**：隔离模式补齐 `sill.storage`、`https:` 网络与每组件独立 partition；`trust: "trusted"` 仍是完整 Node 插件通道。

## 安装说明

- 安装包**未签名**，Windows SmartScreen 会提示一次，选择「更多信息 → 仍要运行」；
- 从 `0.6.0-dev.2` 升级：安装版会自动更新到 0.6.0；绿色版替换文件夹即可（`Sill-data` 保留）；
- 组件开发文档见 [Sill-Components/docs/authoring.md](https://github.com/Enkrid-Rao/sill-components/blob/main/docs/authoring.md)；
- CLI：`npm i -g @heavenlydemon/sill-cli`（0.3.1）。

## 已知问题

- 安装包没有代码签名；
- 组件目录默认走 GitHub raw，国内网络可能需要代理，也可以自行换 jsDelivr / CDN；
- 组件包还没有签名 / 哈希校验；
- `webview` 尚未迁移到 `WebContentsView`。

## English

Sill 0.6.0 is the first stable component-platform release: template widgets with optional
`ui/main.js`, manifest-declared settings, tiered install prompts remembered in `trust.json`,
install / upgrade / install-from-URL / catalog updates, and `system` + `processes` migrated to
template packages. The installer is unsigned; Windows SmartScreen will warn once. Windows 10/11 x64.
